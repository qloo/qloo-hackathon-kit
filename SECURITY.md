# Security Policy

Do not report security vulnerabilities in public issues, pull requests, demos,
or event chat. Report them privately through this repository's
[Report a vulnerability](https://github.com/qloo/qloo-hackathon-kit/security/advisories/new)
form instead.

Never include Qloo API keys, model-provider keys, tokens, participant data, or
internal URLs in a report. Explain how to reproduce the issue with redacted
inputs and the affected kit or harness version.

If a credential is misplaced or exposed, stop using it and email
[ian@qloo.com](mailto:ian@qloo.com) to have it revoked. Identify the credential
by team or participant name only; never include the key.
